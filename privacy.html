最終更新日：2026年11月14日

1. このツールについて

Shorts Uploader（以下「本ツール」）は、運営者本人が管理する YouTube チャンネルに動画を投稿し、視聴データを確認するための個人用ツールです。運営者本人以外の利用は想定していません。

2. 取得する情報

本ツールは、Google の OAuth 認証を通じて、運営者本人が許可した範囲で次の情報にアクセスします。

  • YouTube チャンネルの基本情報（チャンネル名・ID）と投稿済み動画の情報
  • 動画のアップロード・予約投稿に必要な権限
  • YouTube Analytics の視聴データ（再生回数・視聴時間など）

3. 利用目的

取得した情報は、運営者本人のチャンネルへの動画投稿、投稿状況の確認、および動画の改善のための視聴データ確認にのみ使用します。

4. 保存と第三者提供

  • 認証情報と投稿履歴は、運営者本人のパソコン内にのみ保存します。外部のサーバーには保存しません。
  • 取得した情報を第三者に提供・販売することはありません。
  • 通信先は Google の API のみです。

本ツールによる Google API から受け取った情報の利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. アクセス許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへのアクセス許可を取り消せます。
